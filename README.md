# Farming simulator

autor: Nicolas Doktor
rok: 2026
škola: VOŠ, SPŠ A SOŠ Varnsdorf


## Simulátor farmy

### princip:

       - zlepšování farmy, nástrojů, ale hlavně stihnout nasbírat co nejvíce surovin



  ### popis: 
      
       - pole na kterém rostou suroviny se dá vylepšovat i spolu s nástroji se kterými je sbírá

       - hráč musí nasbírat co nejvíce surovin za určitý čas, pokud to nestihne něco se stane
       


Studio: UnrealEngine / Godot
